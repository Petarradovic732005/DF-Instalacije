DF INSTALACIJE + DF SERVIS — JEDNA GITHUB PAGES ADRESA
=======================================================

1. Otvori ZIP i raspakiraj sadržaj.
2. Otvori GitHub repozitorij koji već prikazuje tvoj katalog materijala.
3. U korijenski direktorij (glavnu mapu repozitorija) prenesi sve datoteke i cijelu mapu "servis".
   Važno: datoteka index.html mora biti u glavnoj mapi, a servis/index.html u podmapi servis.
4. U GitHubu prihvati Commit changes i pričekaj objavu Pagesa.
5. Na tvojoj postojećoj adresi (npr. https://materijali-df.github.io/ ako je to adresa repozitorija) 
   otvara se Katalog materijala. Odaberi "Servis bojlera" na vrhu i otvorit će se /servis/.
   Klikom na "Katalog materijala" vraćaš se u katalog. Obje su na istom domenu.

ZAJEDNIČKI SERVISNI NALOZI
-------------------------
- Servis dolazi iz DF SERVIS 2.5: modela, greške i dokumentacija ostaju kao prije.
- Kako bi više uređaja vidjelo ISTE naloge potrebno je dovršiti postavljanje Cloudflare Worker + D1 baze iz
  ranijeg paketa DF_Servis_2_5_Zajednicki_Nalozi_Svi_Uredaji.zip (mapa CLOUDFLARE_WORKER).
- Kada Cloudflare Worker bude objavljen, u servis/config.js zamijeni
  https://OVDJE-TVOJA-WORKER-ADRESA.workers.dev
  stvarnim HTTPS URL-om svojeg Workera.
- Sam GitHub Pages nema bazu podataka; bez Cloudflare postavki zajednički nalozi neće raditi.
- Šifra 0909 je slaba i nije primjerena za stvarne podatke klijenata. Namjesti snažnu tajnu
  na Cloudflare Workeru prije unosa imena, adresa ili telefona.
- Ne objavljuj pristupne ključeve, Workera secret ili stvarne klijentske podatke u GitHub repozitoriju.

NAPOMENE
--------
- Glavna stranica je katalog, servis je u podmapi /servis/.
- Sadržaj kataloga, funkcija ispisa samo troškovnika i servisni priručnici ostaju sačuvani.
- Ako je servis ranije bio na drugoj domeni, lokalno spremljene naloge treba prenijeti
  opcijom uvoza, jer ih preglednici ne dijele između različitih domena.
- Ako se stranica ne ažurira, pokušaj tvrdo osvježiti Ctrl+F5.
